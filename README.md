Diabetes Prediction using MLflow

A binary classification project that predicts whether a patient is diabetic from tabular health measurements, with an SVM (SVC) model and MLflow for experiment tracking and model logging.

Project Structure
.
├── ML_diabeties_Prediction.ipynb   # Exploration and model experimentation notebook
├── diabetes.csv                    # Dataset (features + `Outcome` target)
├── main.py                         # Training script with MLflow tracking
├── pyproject.toml                  # Project metadata and dependencies
└── README.md
